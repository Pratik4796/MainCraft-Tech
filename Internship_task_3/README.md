## 📌 Internship Task 3 – MERN To-Do Application (Full CRUD)

###  Description
In this task, I enhanced the existing To-Do List application by adding
**Edit (Update)** and **Delete** functionalities, completing full CRUD operations.

This task helped me understand how real-world MERN applications handle
data updates and deletions with proper frontend–backend integration.

###  Features
- Add new tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Real-time UI updates without page reload

###  Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB Atlas
- Axios

###  Learning Outcome
- Learned PUT and DELETE HTTP methods
- Improved understanding of REST APIs
- Gained hands-on experience with full CRUD operations in MERN stack
